PHOTO SLOTS — two ways to add pictures.

1) UPLOAD FROM THE SITE (easiest)
   Hover any photo on the site and click "UPLOAD ⤴" (or "CHANGE PHOTO").
   The picture is resized and saved in that browser, so it stays after
   refreshes. The ✕ button removes an uploaded photo again.
   Note: uploads live in the browser you used — they are not included
   if you deploy the site elsewhere. For that, use option 2.

2) DROP FILES INTO THIS FOLDER (permanent, ships with the site)

Use exactly these file names, .jpg or .png:

  me.jpg                          → your photo (polaroid in the PROFILE folder)
  course-english-for-the-arts.jpg → English for the Arts (folder header + course card)
  course-creative-design-thinking.jpg
  course-drawing-techniques.jpg
  course-computer-graphics.jpg
  course-visual-communication.jpg

  entry-001-01.jpg ... entry-001-06.jpg   (English for the Arts, entries 1-6)
  entry-002-01.jpg ... entry-002-06.jpg   (Creative Design Thinking)
  entry-003-01.jpg ... entry-003-06.jpg   (Drawing Techniques & Process)
  entry-004-01.jpg ... entry-004-06.jpg   (Computer Graphics)
  entry-005-01.jpg ... entry-005-06.jpg   (Visual Communication)

  The entry numbers are the entry numbers shown on each entry page
  ("ENTRY 03 / 06" = 03).

Any slot without a picture shows a themed placeholder that says which
file to add — the site never looks broken while photos are missing.
